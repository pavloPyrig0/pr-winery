    All vines, barrels and bottles

    Controls

    WASD / arrows
    Walk (two keys walk diagonally along the paths)
    Shift
    Run
    E Space Enter
    Open the highlighted vine, barrel or bottle on GitHub
    Tab 1 2
    Jump to an area entrance: 1 My PRs, 2 To review (Tab goes to the other one)
    L
    List view
    R
    Refresh from GitHub
    \
    Collapse the side panel
    ?
    This help
    Esc
    Close overlays
    Mouse
    Click to walk, hover a vine for details, wheel to zoom

    Vine states

    • Budbreak draft
    • Pests CI failing
    • Thirsty threads to answer / re-review
    • Ripening in review
    • Ripe approved
    • Drooping review waiting 1–3 days
    • Shrivelling review waiting 3+ days

    Cellar

    • Barrel one of your PRs merged in the last 30 days
    • Bottle a PR you approved (corked while open, wax-sealed once merged)

    Settings

    Create a personal access token (classic) with the repo and read:org scopes. PR Winery only reads data, but classic tokens can't be limited to read-only, so keep it private and set an expiry. It is stored only in this browser's localStorage and sent only to api.github.com.

    Organisation repos protected by SAML SSO need the token authorised for that org: on the tokens page, click Configure SSO next to the token and authorise the org.
